# 10 — Known Gaps: Regression Test Cases

Source: `docs/testing/10-known-gaps.md`. See `00-INDEX.md` for ID scheme/layers.

These tests are different in spirit from the rest of this folder: most rows elsewhere assert "the feature works as intended." These rows assert **current, imperfect, documented behavior** — so that if it silently changes (for better or worse) in a future refactor, a test fails and forces a conscious decision instead of an unnoticed drift. Several are written as intentionally-failing ("red") tests that pin down the *desired* fixed behavior as a to-do — those are marked explicitly below.

## How to maintain this file

- When a gap gets fixed, its row's test flips from "documented current behavior" to "required passing behavior asserting the fix" — update both this file and `docs/testing/10-known-gaps.md` in the same PR.
- Don't let a "green because it documents a gap" test quietly become the reason nobody fixes the gap — these are still visible, named tests that show up in test-run output, which is the point.
